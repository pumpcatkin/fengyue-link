# 自动模型切换（0.14.29）

## 范围

所有实际产出模型文本的入口共用 `AccountBackend.withAutoModel`：

| 入口 | 校验与结果提交 |
| --- | --- |
| 玩家设定整理、修复 | 完整 SSE、新会话编号、结构/质量校验 |
| 初始将领、重抽、发现将领 | 完整 SSE、新会话编号、将领结构校验 |
| 普通将领/俘虏互动 | 完整 SSE、新会话编号、回复及特殊指令校验 |
| 将领记忆整理 | 完整 SSE、新会话编号、记忆结构校验 |
| 联机前置词适配、效果判定、独立视角 | 新建隐藏页面、清空会话、完整输出、业务格式校验 |
| 联机回合生成、刷新回复 | 保存并回读作品及当前会话的模型配置，重新加载后发送；保留联机存档上下文 |

访客镜像和会话配置初始化中立即停止的占位消息不属于内容生成，不更改既有镜像协议。小游戏不拥有账号 token 或选模权限，由宿主统一调用。游戏程序仍完整保存在作品介绍里；本次仅修改宿主，程序摘要及游戏卡版本保持不变。

## 排序

读取账号实时 `/go/api/workspaces/model-list`，以 `provider_name + model_id` 去重；排除明确停用、非文本输出或不支持流式的模型。没有列出的型号不会凭名称猜造。

1. 型号/标签匹配 DeepSeek v4（包括 v4.1 等）且含 Flash，或 GLM 5.3 且含 Flash。
2. Gemini 3.5 及以上版本且含 Flash。
3. 其余可用文本模型。

同层按 `success_rate / model_price` 降序，平均完成耗时 `average_latency` 越低越优先。同分再按价格和稳定键排序。平台 `success_rate` 是百分比（0.5 表示 0.5%，不是 50%），此处“出字率”指成功产出比例，并非 tokens/s。未知价格或成功率放在本层已知数据之后；明确免费且成功率大于零优先；零成功率仍如实保留。平台目录中的名称及统计仅代表平台提供商的标记，不是模型厂商官方规格声明。

每轮遍历全部候选，每个候选最多一次；耗尽后重取目录重排，持续循环，没有三次或其他次数上限。失败等候随轮次递增，最高 30 秒，避免高频请求。空目录也会等待后重新读取。

## 一致性、取消及计费

- 同一作品的配置切换与生成串行，避免两个功能互相覆盖模型配置。只写 `model`，不写世界书、提示词、全局标志或作者作品内容；完成参数按目标模型支持范围裁剪。
- 每次发送前回读验证 `provider/name`。网络失败、超时、空输出、流提前关闭、JSON/业务校验失败都切换下一个候选。
- 在线世界和辅助插件每条实际请求及重试新建会话，等待模型完全结束后才验收；在线世界拒绝重复会话编号。在线世界业务数据只在校验通过后提交。
- 左下角旋转 Logo 显示任务、选模/生成/切换阶段、型号、尝试次数和已知积分消耗；提供取消。减少动态效果的系统设置下使用静态标记。
- 用户取消、账号/作品/房间上下文变化、关闭游戏会终止相应任务；登出/退出终止所有任务。过期请求结果不回写新账号或新游戏。积分不足、登录失效、账号权限类错误结束等待并提示处理，不进行无效扣费尝试。
- 服务端已接收的请求即使本地取消仍可能计费。失败/格式不合格的输出也可能扣分，按平台实际元数据记录，缺项不显示为零。长时间持续重试可能消耗较多积分，可随时取消。
- 在线世界账目保持最近 30 条；插件重试累计已知积分，任何未知项保留 `pointsIncomplete`，不声称未知消耗为零。错误流会关闭 reader，避免旧连接滞留。

## 验证

- `tests/auto-model-router.test.ts`：版本匹配、排序、缺失/零指标、超过三次循环、目录刷新、取消、账号切换、同作品串行、完整业务校验。
- `tests/perspective-split.test.ts`：超时/格式错误后新建隐藏窗口和会话，取消后继续保护独立视角内容。
- `scripts/verify-desktop.cjs`：离线真实 Electron 中验证加载 Logo、动画、尝试次数和取消按钮。
- `FYOW_INSPECT_MODELS=1` 运行 `scripts/configure-grid-companion-work.cjs`：只读实时目录与前 15 个排序结果。
- `FYOW_PROBE_AUTO_MODEL=1`：临时保存原模型配置，首轮本地注入失败（不发生成请求），切换后执行短将领回复、完整 SSE 与结构校验，最后恢复原模型配置并回读。该模式产生真实模型请求和积分消耗，不写地图或评论。

本次实测：平台目录 139 项；首轮本地注入失败后切换到另一提供商的 `glm-5.3-flash`，一次真实生成收到 `message_end`、独立新会话和 99 字符的合格结构化结果，消耗 65 积分。原模型配置已恢复并回读一致。没有批量调用全部提供商来探测速度。
