# 介绍

🎃风月联机工具是一款面向风月作品的多人联机桌面工具，主要提供以下功能：

- 创建或加入联机房间，与其他玩家共同游玩同一作品。
- 房间成员管理、房间对话、回合输入确认和联机进度同步。
- 保存与切换个人角色设定，便于在不同房间中使用。
- 管理当前作品的会话、模型和作品设置。
- 提供可按需启用的多人格式适配、效果判定和独立视角等辅助功能。
- 支持多个账号实例相互隔离运行。
