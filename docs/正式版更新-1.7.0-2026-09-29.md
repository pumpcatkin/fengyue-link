# 1.7.0 正式版：联机回合恢复与游戏编辑器

日期：2026-09-29（北京时间）。来源是两份诊断报告和现有实现；报告中的建议是诊断输入，不是对用户要求的替代。此次不采用报告提出的生成总时限、超时兜底或依赖超时切换模型的方案。

## 联机回合

- 房主监听当前作品、会话的实际生成请求和响应流。以消息编号、会话编号、正文及明确结束事件组合交付结果，不再等待 DOM 节点数增长或积分标签出现。积分缺失显示待确认，不虚构零积分。
- 页面外壳存在不再等于可以发送；输入框通过 DOM 变更事件等待就绪，发送前检查编辑状态和按钮状态。用户取消、页面离开仍可终止等待。
- HTTP/生成错误与连接不确定、中途断流分别记录。不确定请求停止自动重发，避免重复计费；明确失败后的模型重试建立新对话，一次读取完整分页历史，后续重试复用历史而不递归嵌套重试提示词。
- 主生成、在线世界模型、开发模型不新增生成时限；移除了对应固定生成中断逻辑。已有普通页面导航、平台 CRUD、测试运行器的保护机制不等于模型生成期限，本次没有新增它们。
- `/go/api/apps/chat-messages` 明确返回 404/405 时使用已有 installed-app 对话接口；访客停止接口同样支持路由缺失切换。鉴权/积分错误不换接口重发。此兼容性有请求模拟覆盖，不把模拟说成生产节点已实测。
- 成员端等服务端结束后重新获取回复节点；停止请求不再被本地四秒定时器截断。已经存在的占位回复优先复用并只编辑房主正文，避免为了重试而重复创建占位消息。
- 失败保留玩家输入和已取得正文。房主可点击“恢复本轮”：已有正文优先继续后处理或重传；没有完整正文时明确告知费用风险并新建对话重试。成员已写入但回执丢失时，重复结果会重新确认，不再生成一次。

## 编辑与交互

- 编辑区全宽、纵向滚动，左侧内容导航，开发输入置底，窄屏换行；增加“测试与验收”和候选恢复入口。
- 表单序列化不再提前清除脏状态，保存中禁止切换项目。切换、新建、导入、离开会先保留当前草稿。异步回包只更新对应项目。
- 本地版本号阻止旧表单覆盖新草稿；开发候选以后台持久状态为准。开发目标、测试场景和预算归属于各自项目。预算只在发起收费开发时校验，不阻止免费保存。
- 完整配置与结构化页按实际改动合并，双边冲突明确报错。保存草稿不覆盖游戏库运行卡；云端或验收失败前已落盘本地草稿。
- 创建作品后立即保存待发布作品编号。读回或上传失败后复用同一作品，避免重试反复创建。编辑发布严格核对名称、简介、提示词顺序、世界书等字段，历史迁移仍使用自身兼容契约。
- 开发停止仅取消编辑器作用域。诊断日志默认折叠，玩家无需配置内置工具链接。

## Harness 与运行契约

- 持续主模型保留计划、顾问结果和失败证据；不同模型的意见返回主模型判断，不直接替换项目。评审排除所有已知程序作者，而非只排除最后一个作者。
- 增加带摘要前置条件的唯一文本补丁、文件检索、知识检索和分片读取。打包九项版本化知识，明确实现、历史经验、参考与设计稿的区别。
- 世界书条目增加结构和取值校验；评审收到相同运行/测试契约，示例包括必要断言与重新进入后的存档检查。重复同版本同错误会保留候选并暂停，而非继续空转消耗预算。
- 开发工作台作品每次启动重新核对配置，不再只信任旧缓存 ready 标记。
- 测试与真实宿主共享请求 UUID 及 100ms 存档间隔规则。新模板的 `flush-save/1` 在返回前等待落盘确认；不支持此能力的旧卡由宿主提示确认，不伪称已保存。
- **能力边界**：自动玩法验收目前覆盖 `standalone/1` 本地单人模式。疆土已有卡继续手工编辑/发布；自动开发入口提前解释专项宿主验收缺口并阻止无效付费循环。本版本不宣称已具备从零自动复刻完整多人《猎艳疆土》的通用引擎。

## 疆土可靠性

- 对游戏卡公开的行动使用白名单，内部授予将领、回写模型结果等入口不接受游戏卡直接调用；不把客户端边界检查夸大为完整反作弊系统。
- 市场已结算凭据跨重开保存，移除会导致老订单重复结算的即时清空及 1000 条截断。
- 同步锁覆盖云端上传阶段，暂停等待上传退出；评论分块绑定最初作品编号，避免切换作品后把旧分块写到新作品。
- 完整互动档案继续保存，模型即时上下文仅取最近十二条，防止历史无界挤占输入。
- 书信正文和唤醒信息作为同一持久发件任务；先送正文再发唤醒。逐块检查点支持失败恢复，网络失败单列为待投递，不再次调用模型生成同一封信。

## 验证与发布边界

- 单元/集成回归、TypeScript 构建、真实 Electron 玩法测试、真实 renderer/preload 退出存档和提示词回读、1280/420 宽度检查。
- 正式包使用现有 Ed25519 发布身份；签名运行证明、发布清单、安装包、更新索引一致校验。保留测试分支/测试发布，正式更新仍只选择非 prerelease、非 draft 的最新发布。
- 桌面快捷方式在正式包核验通过后指向新程序。未清理玩家存档、账户资料、旧测试包或本地卡片备份。
- 本轮自动验证不等于真实双账号长局联机验收；新增受理/消息/结束事件日志用于后续实局核对。真实供应商长响应和跨节点行为保留为线上观察项。
