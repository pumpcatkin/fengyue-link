# 通用游戏模型任务接口

状态：已实现。日期：2026-10-02。

本接口供 `standalone/1` 新游戏卡在运行时调用当前伴生作品的模型。它不依赖《猎艳疆土》的游戏 ID、七项任务、规则引擎或 intent 白名单。

## 任务声明

编辑器在 `configuration.json.model_tasks` 中维护 `fyow.model-tasks/1` 清单。发布时，任务清单会进入签名摘要覆盖的 `FYOW-PROGRAM/1` manifest；运行时以程序 manifest 为权限源。

每项任务包含：

- `taskId`、`version`
- 固定 `prompt`
- 受限 `inputSchema`、`outputSchema`
- `maxInputBytes`、`maxOutputBytes`
- 宿主计费确认规则

任务只支持受限 JSON Schema。卡片不能声明 URL、作品 ID、Token、请求头、任意平台接口或运行时替换提示词。

## 卡片调用

```js
const requestId = crypto.randomUUID();
parent.postMessage({
  source: "fyow-game-card",
  protocol: "fyow-host/2",
  kind: "request",
  method: "model.run",
  requestId,
  params: {
    taskId: "story.generate",
    idempotencyKey: crypto.randomUUID(),
    input: { choice: "进入森林" }
  }
}, "*");
```

宿主只执行当前程序 manifest 中登记的任务。调用前由宿主显示积分确认；模型使用全新会话，结果必须通过输出 Schema。

## 返回值

```json
{
  "source": "fengyue-host",
  "protocol": "fyow-host/2",
  "kind": "result",
  "requestId": "REQUEST_UUID",
  "ok": true,
  "result": {
    "operationId": "OPERATION_UUID",
    "taskId": "story.generate",
    "taskVersion": 1,
    "output": { "text": "你踏入了发光的森林。" },
    "usage": {
      "input": 2,
      "output": 3,
      "total": 5,
      "source": "model-response",
      "remainingPoints": 995
    }
  }
}
```

`usage` 是卡片可展示的实际消耗信息。平台会话编号、消息编号、凭据、请求头和原始响应不会返回给卡片。

如果平台已经受理并产生积分，但回复随后因流中断、JSON 解析或输出 Schema 校验失败，错误结果仍会携带已确认的 `operationId` 和 `usage`。同一幂等键再次请求时回放同一错误与消耗记录，不会再次调用模型。平台没有提供拆分字段时，`input`、`output` 可以为 `null`；宿主会优先以调用前后余额差补全 `total`。

同一运行会话内，相同 `taskId + idempotencyKey` 会回放已完成结果，不再次调用模型。结构校验失败或平台失败后，卡片应由玩家明确发起新的请求，不自动更换幂等键重试。

## 编辑器验收

当目标要求模型生成功能时，Harness 必须同时生成：

1. `model_tasks` 任务声明与提示词。
2. `fyow-host/2` 的 `model.run` 前端调用。
3. 结果和 `usage` 的界面展示。
4. `tests.json.modelFixtures` 的结构化测试结果，以及显式的 `input/output/total/source/remainingPoints` 消耗夹具。
5. 通过浏览器操作实际触发每一项已声明任务。
6. 在每次调用后的可见页面文本中展示该次 `total` 与 `remainingPoints`；验收按文本证据检查，不绑定固定类名或 DOM 结构。

浏览器验收使用固定夹具，不产生真实积分消耗；正式运行通过宿主调用平台模型并返回实际积分。
